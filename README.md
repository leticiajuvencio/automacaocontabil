Sobre o projeto:

 O Automação Contábil é um projeto desenvolvido para a Contabilidade Frasson, com o objetivo de automatizar e facilitar o processo de conversão de documentos contábeis.
 Atualmente, extratos bancários e outros documentos recebidos em formato PDF precisam passar por um processo manual de conversão PDF → Excel → TXT antes de serem importados para o sistema Domínio. Esse procedimento exige tempo e atenção dos colaboradores, principalmente devido à necessidade de conferir e ajustar as informações antes da importação. Além do trabalho manual, o processo pode estar sujeito a erros, como perda, alteração ou formatação incorreta dos dados, o que pode gerar retrabalho e atrasar as atividades do setor contábil.
 Diante dessa necessidade, o projeto busca desenvolver uma solução web capaz de automatizar esse fluxo, permitindo que os documentos sejam enviados e convertidos de maneira mais prática e padronizada. A proposta é reduzir as etapas manuais envolvidas no processo, diminuir a ocorrência de erros e agilizar a preparação dos arquivos para importação no sistema Domínio.
 Com isso, o Automação Contábil pretende contribuir para uma rotina mais eficiente, organizada e segura, proporcionando maior produtividade para os profissionais da Contabilidade Frasson.
