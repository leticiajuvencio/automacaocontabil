Sobre o projeto

O Automação Contábil é um projeto desenvolvido para a Contabilidade Frasson, com o objetivo de automatizar a conversão de documentos contábeis.

Atualmente, extratos bancários e outros documentos recebidos em PDF precisam passar por um processo manual de conversão PDF → Excel → TXT antes de serem importados para o sistema Domínio. Esse processo consome tempo, pode gerar erros e ocasionar perda ou alteração de informações.

O projeto busca desenvolver uma solução web para automatizar e facilitar esse processo, reduzindo o trabalho manual e tornando a conversão dos documentos mais eficiente.
